# fwv_musik – FWV Musik

Der Musik-Bereich der Mitglieder-App als eigenes Desktop-Programm (macOS,
Linux, Windows): Playlists bearbeiten, Radiosender pflegen, am Computer
hören und den Laptop im Roten Schopf fernbedienen.

Die Bildschirme stammen aus `../fwv_roterschopf`, die Anmeldung aus
`../fwv_core` (`package:fwv_core/desktop.dart`). Alles Weitere:
`docs/flutter-musik-desktop.md`.

    flutter test
    flutter run -d macos     # oder linux, windows

Release: Tag `musik-vX.Y.Z` (`.github/workflows/build-desktop-musik.yml`).
